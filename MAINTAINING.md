# Maintaining Robot Procedures

This is the independently versioned student release. The student entry is README through the MakeCode tutorial URL; main.ts stays empty. The separate robot-procedures-demo repository supplies the completed reference program.

The supplied world is retained under source/. Its files are deliberately excluded from the MakeCode package files list: README installs that world once through customts. Listing both copies compiles the world twice. After editing source files, run `node scripts/rebuild-runtime.mjs` to update that one inline world. Recipe overlays contain no template or customts and retain the current project.

Review current native Blocks availability, parameters/return construction, controlled current-code trials, battle outcomes, saving and exact served content after meaningful changes. Order matching is a behavior check; it does not certify Function structure or learning. Temporary geometric art is intentional in v0.1.0. Instructional source notices are in NOTICE.md.

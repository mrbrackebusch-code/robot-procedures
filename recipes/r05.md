# Return a danger answer

### @explicitHints true

## Return a danger answer

Your danger condition already works. Give that question its own function, then use its true-or-false answer in the planner.

## Make a function that answers

Parameters let you pass values **to** a function. A **return value** lets a function give back a value at the end of a call. This time, the value will be a Boolean: true or false.

Create ``||functions(noclick):inDanger||`` with **two Number inputs**, in this order: ``||variables(noclick):robot||``, then ``||variables(noclick):shieldLimit||``. In the **Edit Function** dialog, add and name each Number parameter, then choose **Done**.

The first input identifies the robot to ask about. The second says how much shield counts as low for this call. Keep these as function inputs so different calls can provide different values. Next you will add a return block to give its answer back.

## Return the comparison's answer

From ``||functions(noclick):Functions||``, add ``||functions(noclick):return 0||`` inside ``||functions(noclick):inDanger||``. Move the two-part danger comparison into its value socket, replacing **0**. Reconnect both sensors to this function's ``||variables(noclick):robot||`` input. Replace the shield comparison's **12** with ``||variables(noclick):shieldLimit||``. Keep the distance comparison at **< 50**.

The complete ``||logic(noclick):and||`` comparison produces true or false, and the return sends that answer back. It supplies an answer in both cases, so the planner can use it whether the robot is in danger or not. ``||functions(noclick):Functions||`` now provides a reporter-shaped call to ``||functions(noclick):inDanger||`` that gives back this Boolean.

There is no order block in this function. Calculating whether the robot is in danger and deciding which action to call are separate jobs.

function inDanger(robot: number, shieldLimit: number): boolean {
    return arenaLab.shieldPoints(robot) < shieldLimit && arenaLab.enemyDistance(robot) < 50
}
```

## Use the answer where you called it

In ``||functions(noclick):planRobot||``, replace the old inline danger comparison with the returned-value call to ``||functions(noclick):inDanger||``. Put the call **in the first branch's condition socket**.

Supply the planner's ``||variables(noclick):robot||`` as the first argument and **12** as the second. The function's Boolean answer now decides whether that branch calls ``||functions(noclick):retreat||``. Keep the later Guard and attack branches unchanged.

Calling ``||functions(noclick):inDanger||`` without using its answer would not make this decision. Here the answer is used immediately by the condition; you do not need a new global variable to hold it.

function planRobot(robot: number) {
    if (inDanger(robot, 12)) {
        retreat(robot)
    } else if (arenaLab.isGuard(robot)) {
        protect(robot)
    } else {
        attack(robot)
    }
}
```

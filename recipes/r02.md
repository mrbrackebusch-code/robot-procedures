## Give different roles different jobs

Keep attack. Add a second named action so a Guard can protect an ally while other robots engage.

## Create the protection action

Create a function named ``||functions(noclick):protect||`` with one **Number** input named ``||variables(noclick):robot||``. Use ``||functions(noclick):attack||`` as your model for the definition and input.

Give the passed robot the **protect** order inside this function. The new order choice is shown here. Keep ``||functions(noclick):attack||`` unchanged so the two names describe two different jobs.

The arena supplies a Guard's role and carries out the protection behavior. Your program chooses whether to use that action for the current robot.

## Choose by role

Inside ``||arenaLab(noclick):when robot needs a plan||``, replace the single action call with ``||logic(noclick):if true then else||``. Put ``||arenaLab(noclick):is robot a Guard||`` in the condition and give that reporter the event's ``||variables(noclick):robot||`` value.

If the answer is true, call ``||functions(noclick):protect||``. Otherwise, call ``||functions(noclick):attack||``. Pass the event's ``||variables(noclick):robot||`` to either call. The assembled example shows one call in each branch.

The role reporter gives a true-or-false answer, so it fits the condition. We ask about the robot supplied by the event; we do not decide its role from a number we happened to see in an earlier scene.

> For this robot, a true role answer runs protect. Otherwise, the same robot is passed to attack.

#### ~ tutorialhint

```blocks
arenaLab.onPlan(function (robot: number) {
    if (arenaLab.isGuard(robot)) {
        protect(robot)
    } else {
        attack(robot)
    }
})
```

## Follow the value when the team changes

## Use both jobs in the arena

Run **Run all with current code** for Recipe 2. Winning the first battle licenses the Guard and opens the second team bay. To try protection in the next fight, choose **Team / equipment** from Base. Use **← / →** to select **Bay 2**, select its class row, then choose **Guard** with **A / Z**. The other bay can keep its existing class. Press **B / X** to return.

Choose **Battles / replay**, select the next battle, then **Fight using current code**. Watch for the Guard's protection and the other robot's engagement. Protect moves and fires near an ally; it does not heal that ally or block bullets. You can change the team or equipment and retry a lost fight without erasing your Functions.

After the battle, point to the definition that gives Protect and the call that selects it. The order result tells you what was submitted; your Blocks show how the function was used.
